## 1. 设计理念

**一句话定位：像一位温和的导师坐在你对面，而不是一套冰冷的考试系统。**

### 1.1 场景洞察

目标用户是**准备技术面试的求职者**——他们普遍处于焦虑、自我怀疑的状态。现有冷蓝色调（#4f6ef7）传递的是「专业、工具感」，与产品「辅导、陪伴」的核心价值存在温度错位。

### 1.2 三个设计关键词

| 关键词 | 含义 | 落地手段 |
|---|---|---|
| **暖** | 降低心理门槛，营造安全感 | 奶油米白画布 + 陶土珊瑚主色 + 暖色阴影 |
| **柔** | 视觉无攻击性，长时间使用不疲劳 | 低饱和色彩、大圆角、极淡阴影、充足留白 |
| **稳** | 建立对「面试官」的信任感 | 清晰的层级秩序、克制的动效、稳定的版式结构 |

### 1.3 设计原则

1. **色彩稀缺原则**：大面积区域只用画布色与白色，彩色仅出现在交互元素（按钮/链接/强调）上——让每一处颜色都有明确语义。
2. **内容优先**：面试对话是核心内容，界面元素做「减法」，气泡与报告面板获得最大视觉权重。
3. **一致性胜过炫技**：所有卡片同一圆角体系、所有阴影同一色相（暖棕灰而非蓝黑）、所有动效同一时长节奏（150ms / 250ms 两档）。
4. **无障碍基线**：正文对比度 ≥ 4.5:1（WCAG AA），主按钮白字对比度 ≥ 4.5:1。

## 2. 设计参考与灵感来源

> 所有参考仅吸收其方法论与气质，色彩体系为本项目原创调校，不直接复制。

| 参考对象 | 吸收点 | 创新调整 |
|---|---|---|
| **Claude（Anthropic）Web UI** | 奶油画布（cream canvas）+ 陶土珊瑚 CTA 的暖色人本主义配色结构；编辑风排版层级 | 主色提亮增饱和（#CC785C → #D97852）更贴合中文年轻用户审美；圆角加大适配「对话气泡」场景 |
| **Premium Utilitarian Minimalism 设计协议** | 暖单色画布、极淡阴影（opacity < 0.05）、bento 卡片栅格、禁用大色块 hero | 保留 Element Plus 组件生态（协议中的禁用项不适用于本项目），阴影改为暖色相 |
| **InterviewAI Mock Interview App UI Kit** | 面试流程的完整状态设计（准备→进行→反馈→复盘）、pill 按钮、圆润卡片 | 桌面端为主的三栏/两栏布局（该 Kit 为移动端），语音页保留其「通话仪式感」 |

## 3. 色彩规范

### 3.1 核心色板

**主色 · 暖珊瑚（Terra Coral）**

```
--brand:        #D97852   主操作色（按钮/链接/激活态/语音波形）
--brand-2:      #C4603A   hover 深化色
--brand-light:  #F3B599   浅强调（选中底/标签底）
--brand-rgb:    217,120,82 阴影与光晕 rgba 用
```

**画布与表面（Surface）**

```
画布（页面背景）   #FAF7F2  奶油米白（替代现有淡蓝渐变）
主表面（卡片）     #FFFFFF
次表面（侧栏/嵌套）#F5F0E8  浅杏灰
表面描边          #EAE2D6  暖灰（替代冷蓝灰边框）
```

**文字（暖炭灰系）**

```
主文字   #3B3833（暖炭，替代现有蓝灰 #243352）
强文字   #2A2722
次文字   #8C8578（暖灰）
禁用     #B8B0A4
```

**语义色（低饱和暖调）**

```
成功   #6B9E6B（鼠尾草绿）  浅底 #EAF2EA
警示   #D9A441（琥珀）      浅底 #FBF3DF
错误   #C65B4E（砖红）      浅底 #F9E9E6
信息   #5B8FA6（灰湖蓝）    浅底 #E6F0F4
```

### 3.2 背景处理

现有 `body` 为冷蓝 radial 渐变，改为**暖色微渐变**（保持柔和光感，避免纯平呆板）：

```css
/* 语义示意，落地时写入 main.css */
background: radial-gradient(1100px 560px at 50% -10%, #FDF4EA 0%, #FAF7F2 55%, #F6F1E9 100%);
```

### 3.3 Element Plus 主题变量映射

Element Plus 组件（按钮/输入框/弹窗/下拉等）通过覆盖其 CSS 变量统一到暖色系，**集中写在 `:root`，与品牌令牌同源**：

```
--el-color-primary:              var(--brand)
--el-color-primary-light-3:       var(--brand-light)
--el-color-primary-light-5/7/8/9: 基于品牌色的暖色阶梯（#E39B7C/#EDBB9F/#F3D2BD/#F9E6D8）
--el-color-success/warning/danger: 对应语义色
--el-text-color-primary/regular:  对应暖炭文字系
--el-border-color:                #EAE2D6
--el-fill-color-blank:            #FFFFFF
--el-fill-color-light:            #F5F0E8
--el-bg-color-overlay:            #FFFFFF
```

### 3.4 对比度验证（WCAG AA）

| 组合 | 对比度 | 判定 |
|---|---|---|
| 主文字 #3B3833 / 画布 #FAF7F2 | ≈ 11.5:1 | AAA |
| 次文字 #8C8578 / 白 | ≈ 3.4:1 | 仅限 13px 以上辅助文字 |
| 品牌色 #D97852 / 白（按钮白字） | ≈ 3.9:1 | 按钮≥14px 半粗体可用（AA 大字/大组件） |
| 品牌深色 #C4603A / 白 | ≈ 4.6:1 | AA |
| 链接文字 #C4603A / 画布 | ≈ 4.9:1 | AA |

> 关键交互文字（链接、小号强调）统一使用 `--brand-2`（更深）而非 `--brand`，保证小字可读性。

### 3.5 令牌迁移对照表

| 现有令牌 | 现值（冷蓝） | 新值（暖珊瑚） |
|---|---|---|
| `--brand` | #4F6EF7 | #D97852 |
| `--brand-2` | #6482F8 | #C4603A |
| `--brand-light` | #7A93FF | #F3B599 |
| `--brand-rgb` | 79,110,247 | 217,120,82 |
| `--ink` | #243352 | #3B3833 |
| `--ink-strong` | #1E2C46 | #2A2722 |
| `--text` | #56637A | #6E675C |
| `--muted` | #7B879C | #8C8578 |
| `--border` | #E7ECF4 | #EAE2D6 |
| `--radius` | 16px | 16px（不变） |

> 落地时需全库排查散落的冷色硬编码（如 ChatView 中 `#56637a`、`#e2e8f2`、`#9db2e8` 等），统一替换为令牌引用——这同时是消除 CSS 纪律测试潜在违规项的机会。

## 4. 排版规范

### 4.1 字体栈

保持系统字体（零新增依赖，加载即生效，中文渲染稳定）：

```css
font-family: "PingFang SC", "Microsoft YaHei", "Segoe UI",
             "Hiragino Sans GB", system-ui, -apple-system, sans-serif;
```

数字（计时器/分数）追加等宽稳定性：`font-variant-numeric: tabular-nums;`

### 4.2 字阶（Type Scale）

| 级别 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| H1 页面标题 | 22px / 1.3 | 700 | 「面试官小P」品牌名 |
| H2 区块标题 | 18px / 1.4 | 600 | 弹窗标题、报告章节 |
| H3 条目标题 | 16px / 1.4 | 600 | 卡片标题、统计数值 |
| Body 正文 | 14px / 1.65 | 400 | 聊天气泡、表单默认 |
| Body-L 导语 | 16px / 1.7 | 400 | 欢迎语、hint 文案 |
| Caption 辅助 | 13px / 1.5 | 400 | 标签、meta、说明 |
| Caption-S 微注 | 12px / 1.4 | 400 | 侧栏备注、时间戳 |

**层级关系**：标题间距上 24px / 下 10px；段落间 8px；行高正文 1.65 保证长对话阅读舒适。

### 4.3 中文排版细节

- 全角标点悬挂不处理（系统字体已较优），但气泡内长段落 `letter-spacing: 0.2px` 微调密度
- 数字与中文间自动空格由内容层保证（如「已挑选 3 道」）

## 5. 空间与布局规范

### 5.1 间距体系（8px 网格）

```
4 / 8 / 12 / 16 / 24 / 32 / 48
```

- 卡片内边距：16px（窄卡）/ 24px（弹窗）
- 页面左右留白：16px（现有）/ 移动端 8px
- 区块间距：24px

### 5.2 圆角体系

| 层级 | 值 | 应用 |
|---|---|---|
| 微 | 8px | 标签、小按钮、输入框 |
| 标准 | 12px | 主按钮、下拉 |
| 卡片 | 16px | 卡片、气泡、面板（沿用现有 `--radius`） |
| 大 | 20px | 弹窗、登录卡（沿用现有） |
| 胶囊 | 999px | chips、用户胶囊、悬浮通话钮 |

### 5.3 阴影体系（暖色相、极淡、两级）

```css
/* 层级1：静态卡片 —— 替代现有蓝黑阴影 */
--shadow-card: 0 2px 12px rgba(120, 90, 60, 0.06);

/* 层级2：悬浮/弹出（下拉、抽屉、悬浮钮）*/
--shadow-float: 0 8px 28px rgba(120, 90, 60, 0.14);
```

> 全站阴影统一为**暖棕灰**色相（rgba 120,90,60），这是「暖感」的隐性来源之一；现有 `rgba(31,58,102,…)` 冷蓝阴影全部替换。

### 5.4 视觉层次优先级

```
第1层（最重）：聊天内容区 —— 纯白表面 + 最深文字
第2层：主操作元素 —— 珊瑚色实心按钮
第3层：结构性容器 —— 次表面 #F5F0E8 + 描边（不投影）
第4层：背景画布 —— 奶油米白渐变
```

## 6. 组件规范

> 以下组件规范同时给出 Element Plus 定制点，落地时通过「令牌覆盖 + 少量全局样式」实现，**不引入新组件库**。

### 6.1 按钮

| 变体 | 样式 | 使用场景 |
|---|---|---|
| Primary 实心 | 珊瑚底 #D97852 + 白字，圆角 12px，高度 40px；hover → #C4603A + 上浮 1px + `--shadow-float` | 发送、登录、开始面试 |
| Secondary 描边 | 白底 + #EAE2D6 描边 + 主文字色；hover → 描边转 `--brand-light`、底转 #FDF6F1 | 题库、取消、返回首页 |
| Text 文字 | 纯文字 #C4603A；hover → 底色 #FBEEE6（8px 圆角） | 次要操作 |
| 危险 | 语义砖红实心 | 退出登录 |

通用：过渡 `all .15s ease`；loading 态显示旋转图标且禁点；focus-visible 出现 2px `--brand-light` 外环（键盘可达性）。

### 6.2 表单

- 输入框：高度 40px，圆角 8px，描边 #EAE2D6；focus 描边转 `--brand` + **3px 珊瑚浅光晕** `rgba(217,120,82,.12)`（替代默认蓝光）
- 标签：label-position=top（登录页现有），字色用次文字 #8C8578
- 校验错误：描边 #C65B4E + 错误文字 13px

### 6.3 卡片

```css
/* 标准卡片（统计卡/欢迎卡/题库条目）*/
background: #FFFFFF;
border: 1px solid #EAE2D6;
border-radius: 16px;
box-shadow: var(--shadow-card);
padding: 16px;
transition: box-shadow .25s, border-color .25s, transform .15s;
```

- 交互卡片 hover：描边 → `--brand-light`，阴影 → float 级，不上浮（克制）
- 嵌套卡片（侧栏内）：降级为「次表面色块 + 无边框无阴影」

### 6.4 聊天气泡

| 角色 | 样式 |
|---|---|
| 小P（assistant） | 白底 + #EAE2D6 描边 + 圆角 16px（左上角 4px 制造对话指向），左侧 32px 圆形头像 |
| 用户（user） | 珊瑚浅底 #FBEEE6（或 `--brand-light` 30% 透明度）+ 深暖文字，右对齐 |
| 报告面板 | 顶级容器：白底大卡 + 20px 圆角 + float 阴影 + 顶部 4px 珊瑚渐变饰条，内部评分用语义色徽章 |

- 气泡间距 12px，流式输出时尾部跟随呼吸光标（` ▍`闪烁 1s 循环）

### 6.5 导航与头部

- 顶栏：透明（融入画布），品牌头像 56px 圆形白描边 2px + 暖阴影
- 用户胶囊：白底描边胶囊（现有形态保留），hover 描边转珊瑚
- 在线状态点：鼠尾草绿 #6B9E6B + 呼吸动画（现有保留，换色）

### 6.6 语音通话页组件（详见 7.3）

- 通话按钮：挂断态用语义砖红，接通态用品牌珊瑚——形成「暖色=开始，红=结束」直觉
- 音频波形：五根柱子由珊瑚渐变（#D97852 → #F3B599）驱动

### 6.7 图标

沿用 Element Plus Icons（@element-plus/icons-vue），不新增图标依赖；仅统一色值随文字色继承。

## 8. 交互流程与状态设计

### 8.1 核心交互流程

**流程A：首次面试（新用户）**

```
登录 → 欢迎卡（模拟面试/辅导答疑/定制面试 三卡横排）
     → 选模式 → persona 选择 → 自动开聊 → 流式回复
     → 5题结束 → 报告面板滑入 → 下载 .md
```

**流程B：语音面试（定制用户）**

```
ChatView 顶部出现「定制面试已就绪」浅珊瑚提示条
     → 点击开始 → 进入 VoiceView → 接通(珊瑚钮) → 问候播报
     → 聆听(电平条) → 用户说话 → 打断可点状态条 → 播报(波形)
     → 挂断(砖红钮) → 回到文字版继续
```

**流程C：题库选题**

```
题库按钮 → 弹窗 → 筛选/搜索 → 多选（行左侧珊瑚色选中竖条+浅底）
     → 开始面试 → 弹窗关闭 → ElMessage 成功提示（暖色）
```

### 8.2 交互状态设计规范（状态矩阵）

### 8.3 动效规范

| 动效 | 时长/曲线 | 应用 |
|---|---|---|
| 微反馈 | 150ms ease | hover 描边/底色、按钮上浮 |
| 容器过渡 | 250ms ease | 弹窗、抽屉、阴影层级切换 |
| 呼吸循环 | 2.2s ease-in-out | 在线点（现有保留）、流式光标 1s |

**动效纪律**：无页面级大动画；弹窗沿用 Element Plus 默认 fade+zoom（随主题变量变色）；hover 上浮仅限按钮与悬浮钮，卡片不上浮。

## 10. 技术可行性说明

| 设计要求 | 实现路径 | 风险 |
|---|---|---|
| 色彩全面替换 | 改 `main.css` `:root` 令牌值（第 3.5 节对照表） | 低——令牌机制现成；需排查散落硬编码冷色值 |
| Element Plus 组件换肤 | `:root` 覆盖 `--el-*` 变量，不动组件源码 | 低——官方支持路径 |
| 阴影/圆角/间距体系 | 令牌化（新增 `--shadow-card/float`） | 低 |
| 气泡/卡片/报告面板 | 现有组件结构不变，仅样式层改造 | 低 |
| 骨架屏/呼吸光标 | 纯 CSS animation | 低 |
| 移动端 | 沿用 820px 断点与现有抽屉 | 低 |
| **测试纪律** | 改样式后运行 `python -m pytest`，`test_css_discipline.py` 必须通过；令牌值均为具体值无自引用，天然合规 | — |
| **构建流程** | 改完 `npm run build` 产物由后端托管 | 现有流程 |

**明确不做**（本期边界）：暗色模式、多语言字体切换、插画系统、新图标库、页面结构重构——均为后续可选迭代。
